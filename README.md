# MyThings

A single-user, local-first to-do app with a Things 3-style UI. No backend, no accounts — everything lives in the browser (IndexedDB via Dexie).

See `docs/brief.md`, `docs/plan.md`, and `docs/design.md` for background.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
