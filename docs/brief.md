# MyThings — Project Brief

A web-based to-do app with a [Things 3](https://culturedcode.com/things/)-style UI: clean, minimalist, fast, keyboard-first.

## Scope (v1)

- **Users:** Single user. No auth/accounts.
- **Persistence:** Local-first — browser storage only. No backend, no database.
- **Views:** Today, Upcoming, Projects, Areas.
- **Features:** Areas, tags, "This Evening", recurring tasks, smooth micro-interactions.
